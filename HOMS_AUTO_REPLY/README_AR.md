# HOMS AUTO REPLY

تطبيق Android (Kotlin + Jetpack Compose) يرد تلقائيًا على المكالمات الواردة ويشغّل رسالتك الصوتية المسجلة، ثم ينهي المكالمة.

## القيد التقني (مهم)
Android لا يوفر لتطبيق عادي واجهة لإدخال صوت داخل المسار الصاعد للمكالمة الخلوية. لذلك يعمل التطبيق هكذا:
- يرد على المكالمة بـ `TelecomManager.acceptRingingCall()`.
- يشغّل التسجيل عبر **مكبر الهاتف بأعلى مستوى** فيلتقطه ميكروفون الهاتف ويسمعه المتصل.
- ينهي المكالمة بـ `TelecomManager.endCall()` بعد انتهاء التسجيل.

وصول الصوت وجودته يختلفان حسب الجهاز، وبعض الشركات تقمع صدى المكبر أثناء المكالمات. الحل الجذري يتطلب روت أو صلاحيات نظام.

## بناء الـ APK
1. افتح مجلد المشروع في Android Studio (Hedgehog أو أحدث، JDK 17).
2. انتظر انتهاء Gradle Sync (يحتاج إنترنت أول مرة).
3. من القائمة: Build > Build Bundle(s) / APK(s) > Build APK(s).
4. الملف في: `app/build/outputs/apk/debug/app-debug.apk`
5. انقله إلى الهاتف وثبّته (فعّل التثبيت من مصدر غير معروف).

ملاحظة: ملف gradle-wrapper.jar غير مضمّن، وAndroid Studio ينشئه تلقائيًا عند المزامنة.

## الاستخدام
1. افتح التطبيق وامنح الأذونات.
2. سجّل رسالتك، استمع إليها، ثم اضغط حفظ.
3. اختر الشريحة إن كان الهاتف ثنائي الشريحة.
4. اضغط تفعيل الرد التلقائي، وستظهر الحالة "نشط" مع إشعار دائم.
5. من إعدادات البطارية اسمح للتطبيق بالعمل في الخلفية.

## ملاحظات
- لا يبدأ تلقائيًا بعد إعادة تشغيل الهاتف؛ افتح التطبيق مرة بعد الإقلاع.
- رقم المتصل غير معروض لأن قراءته تتطلب إذن سجل المكالمات الذي لا يحتاجه التطبيق.
- الحد الأدنى Android 10، وقد تمنع بعض الأجهزة الرد الآلي أو تتأخر.
